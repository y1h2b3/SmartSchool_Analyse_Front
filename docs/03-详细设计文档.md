## 1. 设计概述

本文档基于《概要设计文档》进行细化，详细阐述各模块的类设计、接口设计、数据流转、算法实现等技术细节，为开发人员提供精确的实现指导。

### 1.1 设计原则
- **单一职责**: 每个类只负责一项职责
- **开闭原则**: 对扩展开放，对修改关闭
- **依赖倒置**: 面向接口编程
- **组合优于继承**: 使用组合关系而非继承
- **DRY原则**: Don't Repeat Yourself

### 2.1 分层架构

```
┌─────────────────────────────────────────────────────────┐
│                     Controller Layer                     │
│  StudentController, HealthController, PayController...  │
│  职责: HTTP请求处理、参数校验、响应封装                    │
└─────────────────────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│                      Service Layer                       │
│  StudentService, UserHealthService, OrdersService...    │
│  职责: 业务逻辑、事务管理、业务规则                        │
└─────────────────────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│                      Mapper Layer                        │
│  StudentMapper, UserHealthMapper, OrdersMapper...       │
│  职责: 数据访问、SQL执行、对象映射                         │
└─────────────────────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────┐
│                     Database Layer                       │
│                    MySQL + Redis                         │
└─────────────────────────────────────────────────────────┘
```

### 2.2 分层职责

**Controller层:**
- 接收HTTP请求，提取参数
- 参数校验（基础验证）
- 调用Service层处理业务
- 封装响应结果（Result<T>）
- 异常捕获与处理
- 日志记录（操作日志）

**Service层:**
- 实现业务逻辑
- 事务边界控制（@Transactional）
- 业务规则验证
- 多表操作协调
- 缓存操作
- 调用外部服务

**Mapper层:**
- 继承MyBatis-Plus BaseMapper
- 自定义复杂查询SQL
- 实体与数据库映射

#### 3.1.5 核心算法

**密码加密算法（SaltMD5Util）**
```java
public class SaltMD5Util {
    /**
     * 生成加盐密码
     * @param password 原始密码
     * @return 加密后的密码（格式: salt$hash）
     */
    public String generateSaltPassword(String password) {
        // 1. 生成随机盐值（16位）
        String salt = generateSalt(16);
        
        // 2. 密码+盐值组合
        String combined = password + salt;
        
        // 3. MD5哈希
        String hash = md5(combined);
        
        // 4. 返回格式: salt$hash
        return salt + "$" + hash;
    }
    
    /**
     * 验证密码
     * @param inputPassword 用户输入的密码
     * @param storedPassword 存储的密码（salt$hash格式）
     * @return 是否匹配
     */
    public boolean verifySaltPassword(String inputPassword, String storedPassword) {
        // 1. 分离盐值和哈希值
        String[] parts = storedPassword.split("\\$");
        String salt = parts[0];
        String storedHash = parts[1];
        
        // 2. 使用相同盐值计算输入密码的哈希
        String inputHash = md5(inputPassword + salt);
        
        // 3. 比较哈希值
        return inputHash.equals(storedHash);
    }
}
```

**预警检测算法**
```java
public class HealthAlertEngine {
    private List<AlertRule> rules;  // 规则列表
    
    /**
     * 检测健康数据并触发预警
     */
    public List<HealthWarningNotification> checkHealth(UserHealth health) {
        List<HealthWarningNotification> alerts = new ArrayList<>();
        
        // 遍历所有规则
        for (AlertRule rule : rules) {
            // 获取字段值
            Object fieldValue = getFieldValue(health, rule.getFieldName());
            
            // 检查是否触发条件
            if (rule.getCondition().match(fieldValue)) {
                // 生成预警通知
                HealthWarningNotification alert = createAlert(health, rule, fieldValue);
                alerts.add(alert);
                
                // 发送通知
                sendNotifications(alert, rule);
            }
        }
        
        return alerts;
    }
    
    /**
     * 发送通知
     */
    private void sendNotifications(HealthWarningNotification alert, AlertRule rule) {
        // 1. 系统内通知
        notificationService.sendSystemNotification(alert);
        
        // 2. 如果是高级预警，发送短信
        if (rule.isSmsEnabled() && "高级".equals(rule.getAlertLevel())) {
            smsService.sendAlertSms(alert);
        }
    }
}
```

#### 3.2.4 BMI计算算法

```java
public class HealthCalculator {
    /**
     * 计算BMI
     * @param height 身高(cm)
     * @param weight 体重(kg)
     * @return BMI值
     */
    public static BigDecimal calculateBMI(BigDecimal height, BigDecimal weight) {
        if (height == null || weight == null || 
            height.compareTo(BigDecimal.ZERO) <= 0) {
            return null;
        }
        
        // BMI = 体重(kg) / 身高²(m)
        BigDecimal heightInMeter = height.divide(new BigDecimal(100), 2, RoundingMode.HALF_UP);
        BigDecimal heightSquared = heightInMeter.multiply(heightInMeter);
        
        return weight.divide(heightSquared, 2, RoundingMode.HALF_UP);
    }
    
    /**
     * 根据BMI判断体型
     * @param bmi BMI值
     * @return 体型分类
     */
    public static String classifyBodyType(BigDecimal bmi) {
        if (bmi == null) return "未知";
        
        if (bmi.compareTo(new BigDecimal("18.5")) < 0) {
            return "偏瘦";
        } else if (bmi.compareTo(new BigDecimal("24")) < 0) {
            return "正常";
        } else if (bmi.compareTo(new BigDecimal("28")) < 0) {
            return "偏胖";
        } else {
            return "肥胖";
        }
    }
}
```

```java
public enum OrderStatus {
    PENDING_PAYMENT("待支付"),
    PAID("已支付"),
    SHIPPING("配送中"),
    COMPLETED("已完成"),
    CANCELLED("已取消");
    
    private String description;
    
    // 状态流转规则
    public boolean canTransitionTo(OrderStatus target) {
        switch (this) {
            case PENDING_PAYMENT:
                return target == PAID || target == CANCELLED;
            case PAID:
                return target == SHIPPING;
            case SHIPPING:
                return target == COMPLETED;
            case COMPLETED:
            case CANCELLED:
                return false; // 终态不能再流转
            default:
                return false;
        }
    }
}
```

```java
    Orders order = ordersService.getById(orderId);
    if (order == null || !"待支付".equals(order.getStatus())) {
        throw new BusinessException("订单不存在或状态异常");
    }
    
    // 2. 构建支付请求
    AlipayTradePagePayRequest request = new AlipayTradePagePayRequest();
    request.setNotifyUrl(NOTIFY_URL);   // 异步回调地址
    request.setReturnUrl(RETURN_URL);   // 同步跳转地址
    
    // 3. 设置业务参数
    JSONObject bizContent = new JSONObject();
    bizContent.put("out_trade_no", order.getOrderId());         // 商户订单号
    bizContent.put("total_amount", order.getTotalPrice());      // 订单金额
    bizContent.put("subject", "药品购买-" + order.getDrugId()); // 订单标题
    bizContent.put("product_code", "FAST_INSTANT_TRADE_PAY");  // 产品码
    request.setBizContent(bizContent.toString());
    
    // 4. 调用SDK生成支付表单（HTML）
    String form = alipayClient.pageExecute(request).getBody();
    
    // 5. 返回HTML表单（浏览器会自动提交到支付宝）
    response.setContentType("text/html;charset=UTF-8");
    response.getWriter().write(form);
    response.getWriter().flush();
}

@PostMapping("/notify")
public String notify(HttpServletRequest request) {
    try {
        // 1. 获取支付宝回调参数
        Map<String, String> params = getParamsMap(request);
        
        // 2. 验证签名（防止伪造回调）
        boolean signVerified = AlipaySignature.rsaCheckV1(
            params, 
            ALIPAY_PUBLIC_KEY, 
            CHARSET, 
            SIGN_TYPE
        );
        
        if (!signVerified) {
            return "failure"; // 签名验证失败
        }
        
        // 3. 获取回调信息
        String outTradeNo = params.get("out_trade_no");     // 商户订单号
        String tradeStatus = params.get("trade_status");    // 交易状态
        
        // 4. 处理业务（注意幂等性！）
        if ("TRADE_SUCCESS".equals(tradeStatus)) {
            ordersService.handlePaySuccess(outTradeNo);
        }
        
        // 5. 返回success（必须返回，否则支付宝会重复回调）
        return "success";
        
    } catch (Exception e) {
        log.error("支付回调处理失败", e);
        return "failure";
    }
}
```

```java
public void handlePaySuccess(String orderId) {
    // 1. 查询订单（加锁，防止并发）
    Orders order = ordersMapper.selectForUpdate(orderId);
    
    // 2. 幂等性判断
    if (!"待支付".equals(order.getStatus())) {
        log.warn("订单{}已处理，忽略重复回调", orderId);
        return;
    }
    
    // 3. 更新订单状态
    order.setStatus("已支付");
    order.setPayTime(new Date());
    order.setPayMethod("支付宝");
    ordersMapper.updateById(order);
    
    // 4. 扣减库存
    drugsService.decreaseStock(order.getDrugId(), order.getQuantity());
    
    // 5. 通知后勤
    notificationService.notifyStaff(order);
    
    // 6. 记录流水
```

```java
public class Result<T> {
    private Integer code;
    private String message;
    private T data;
    
    // 成功响应
    public static <T> Result<T> ok(T data) {
        return build(data, ResultCodeEnum.SUCCESS);
    }
    
    // 失败响应
    public static <T> Result<T> fail(String message) {
        return build(null, ResultCodeEnum.ERROR.getCode(), message);
    }
    
    // 自定义响应
    public static <T> Result<T> build(T data, ResultCodeEnum codeEnum) {
        return build(data, codeEnum.getCode(), codeEnum.getMessage());
    }
    
    private static <T> Result<T> build(T data, Integer code, String message) {
        Result<T> result = new Result<>();
        result.setCode(code);
        result.setMessage(message);
        result.setData(data);
        return result;
    }
}
```

```java
     * 获取缓存
     */
    public <T> T get(String key, Class<T> clazz) {

    }

    public void delete(String key) {
```

```java
@RestControllerAdvice
@Slf4j
public class GlobalExceptionHandler {
    
    /**
     * 业务异常
     */
    @ExceptionHandler(BusinessException.class)
    public Result<?> handleBusinessException(BusinessException e) {
        log.warn("业务异常: {}", e.getMessage());
        return Result.fail(e.getMessage());
    }
    
    /**
     * 参数校验异常
     */
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<?> handleValidationException(MethodArgumentNotValidException e) {
        String message = e.getBindingResult()
            .getFieldErrors()
            .stream()
            .map(FieldError::getDefaultMessage)
            .collect(Collectors.joining(", "));
        return Result.build(null, ResultCodeEnum.PARAM_ERROR.getCode(), message);
    }
    
    /**
     * 认证异常
     */
    @ExceptionHandler(NotLoginException.class)
    public Result<?> handleNotLoginException(NotLoginException e) {
        return Result.build(null, ResultCodeEnum.UNAUTHORIZED);
    }
    
    /**
     * 系统异常
     */
    @ExceptionHandler(Exception.class)
    public Result<?> handleException(Exception e) {
        log.error("系统异常", e);
        return Result.fail("系统异常，请联系管理员");
    }
}
```

#### 2.2.2 Result（统一响应包装器）
```java
public class Result<T> {
    private Integer code;
    private String message;
    private T data;
    
    public static <T> Result<T> ok(T data) {
        return build(data, ResultCodeEnum.SUCCESS);
    }
}
```
**职责:** 统一API响应格式 `{code, message, data}`

#### 2.2.3 StudentController（示例控制器）
```java
@RestController
@Tag(name = "学生管理")
@AllArgsConstructor
@SaCheckLogin(type = StpUtil.TYPE)
public class StudentController {
    private StudentService studentService;
    private LogsDataService logsDataService;
    
    @GetMapping("/student")
    @Operation(summary = "查询带分页所有学生")
    public Result<PageDTO<StudentVo>> findAllStudent(PageQuery pageQuery) {
        Page<Student> students = studentService.findAllStudent(pageQuery);
        // 转换VO并返回
        return getPageDTOResult(students);
    }
    
    @PostMapping("/student")
    public Result addStudent(@RequestBody Student student, HttpServletRequest request) {
        student.setType("学生");
        student.setStatus(1);
        boolean b = studentService.save(student);
        if (b) {
            logsDataService.addLogsData(/*记录日志*/);
            return Result.ok(null);
        }
        return Result.build(null, ResultCodeEnum.ERROR);
    }
}
```
**关键点:**
- `@SaCheckLogin`: Sa-Token鉴权注解
- 操作后记录日志（`logsDataService`）
- 统一返回`Result`

#### 2.2.4 StudentServiceImpl（业务实现）
```java
@Service
public class StudentServiceImpl 
    extends ServiceImpl<StudentMapper, Student> 
    implements StudentService {
    
    @Override
    public Page<Student> findAllStudent(PageQuery pageQuery) {
        Page<Student> page = new Page<>(pageQuery.getCurrent(), pageQuery.getSize());
        return this.page(page);
    }
}
```
**关键点:**
- 继承`ServiceImpl`获得CRUD能力
- 分页使用MyBatis-Plus的`Page`

### 3.2 核心文件详解

#### 3.2.1 request.ts（HTTP请求封装）
```typescript
import axios from 'axios'

const service = axios.create({
  baseURL: import.meta.env.VITE_BASE_API,
  timeout: 10000
})

// 请求拦截器：添加Token
service.interceptors.request.use(
  config => {
    const token = getToken()
    if (token) {
      config.headers['Authorization'] = `Bearer ${token}`
    }
    return config
  }
)

// 响应拦截器：统一错误处理
service.interceptors.response.use(
  response => response.data,
  error => {
    ElMessage.error(error.message)
    return Promise.reject(error)
  }
)
```

## 10. 常见问题

### Q1: 数据库连接失败
**A:** 检查`application.yaml`中的数据库配置，确认MySQL已启动

### Q2: Redis连接超时
**A:** 检查Redis配置，确认Redis服务运行正常

### Q3: 前端请求404
**A:** 确认后端API已启动，检查Vite代理配置

### Q4: Token过期
**A:** Sa-Token默认30天，可在配置中调整`sa-token.timeout`

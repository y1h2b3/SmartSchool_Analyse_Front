## 1. 测试计划

### 1.1 测试目标
- 验证系统功能完整性与正确性
- 确保系统性能满足需求指标
- 验证安全性与数据完整性
- 保证用户体验达标
- 测试覆盖率 ≥ 85%

### 1.2 测试范围
**包含:**
- 功能测试（人员管理、健康监测、医疗服务、订单支付、通知、系统管理）
- 接口测试（API正确性、边界值、异常处理）
- 性能测试（响应时间、并发、压力）
- 安全测试（认证授权、SQL注入、XSS）
- 兼容性测试（浏览器、设备）
- 用户体验测试

**不包含:**
- 第三方服务内部测试（支付宝、OpenAI）
- 智能设备硬件测试

### 1.3 测试策略

| 测试类型 | 覆盖度 | 执行阶段 | 工具 |
|---------|-------|---------|------|
| 单元测试 | 60%+ | 开发阶段 | JUnit, Jest |
| 集成测试 | 80%+ | 开发完成后 | SpringBootTest |
| 系统测试 | 95%+ | 集成测试后 | 手工+自动化 |
| 回归测试 | 100% | 每次发布前 | 自动化脚本 |
| 性能测试 | 核心接口 | 系统测试阶段 | JMeter |
| 安全测试 | 全量 | UAT前 | OWASP ZAP |

### 1.4 测试环境

| 环境 | 配置 | 用途 |
|------|------|------|
| 开发环境 | 本地环境 | 开发自测 |
| 测试环境 | 2C4G×2, MySQL, Redis | 功能测试、集成测试 |
| 预生产环境 | 4C8G×2 | 性能测试、UAT |
| 生产环境 | 按需配置 | 生产发布 |

### 1.5 测试团队

## 9. 自动化测试

### 9.1 自动化测试框架
- 后端: JUnit 5 + Mockito
- 前端: Jest + Vue Test Utils
- E2E: Cypress / Playwright
- API: Postman + Newman

### 9.2 自动化用例（示例）

```java
@SpringBootTest
public class StudentServiceTest {
    @Autowired
    private StudentService studentService;
    
    @Test
    @DisplayName("测试新增学生")
    public void testAddStudent() {
        Student student = new Student();
        student.setStudentId("TEST001");
        student.setName("测试学生");
        student.setPhone("13800138000");
        
        boolean result = studentService.save(student);
        assertTrue(result);
        
        // 清理测试数据
        studentService.removeById(student.getId());
    }
    
    @Test
    @DisplayName("测试学号重复")
    public void testDuplicateStudentId() {
        // 先插入一条
        Student student1 = createTestStudent("DUP001");
        studentService.save(student1);
        
        // 再插入相同学号
        Student student2 = createTestStudent("DUP001");
        assertThrows(DuplicateKeyException.class, () -> {
            studentService.save(student2);
        });
    }
}
```
